# Security Policy

## Reporting a Vulnerability

If you find a security issue, please do not open a public issue with exploit details.

Send a private report to the maintainers of this repository, including:
- affected endpoint/module
- reproduction steps
- expected vs actual behavior
- impact assessment

We will acknowledge the report and provide follow-up on triage/remediation.

## Scope Notes

This repository is a demo/reference application. It is not intended to be used as-is
for production workloads without additional hardening and operational controls.
