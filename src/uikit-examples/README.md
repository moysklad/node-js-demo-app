# Модуль «Примеры UI Kit»

Вкладка основного iframe с примерами компонентов `@moysklad/uikit`. Сейчас — заглушка:
наполнение примерами запланировано отдельно.

## Карта файлов

| Файл                     | Роль                                              |
|--------------------------|---------------------------------------------------|
| `client/ExamplesTab.tsx` | Содержимое вкладки (браузерный код, React + uikit) |

## Где модуль подключается к общему коду

Все такие места помечены: `grep -rn "feature:uikit-examples" src/`.

- `src/features/entry/iframe/client/IframePage.tsx` — `Tabs.Item` и рендер `ExamplesTab`.

## Как убрать модуль

Удалите каталог `src/uikit-examples/` и две помеченные строки в `IframePage.tsx`.
Сам UI Kit при этом остается: на нем построены все страницы решения, см. раздел «UI Kit» в корневом `README.md`.
